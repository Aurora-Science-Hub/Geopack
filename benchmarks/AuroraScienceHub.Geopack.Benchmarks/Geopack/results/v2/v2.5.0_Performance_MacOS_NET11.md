# Performance Comparison: v2.5.0 Optimizations

## Environment

- **Hardware:** Apple M1 Pro, ARM64
- **OS:** macOS 27.2
- **Runtime:** .NET 11.0.0-rc.2.26504.105
- **BenchmarkDotNet:** 0.15.8
- **Toolchain:** InProcessNoEmitToolchain
- **Job:** ShortRun, one launch, three warmup iterations, three measured iterations
- **Tiered compilation:** disabled by the benchmark project for stable pilot and workload measurements

The baseline and optimized runs used the same repaired benchmark suite and configuration. Benchmark methods return their results to prevent JIT elimination of unused computations. Older reports containing near-zero measurements or targeting an incompatible runtime are not used as this baseline.

Command:

```bash
dotnet run \
  --project benchmarks/AuroraScienceHub.Geopack.Benchmarks/AuroraScienceHub.Geopack.Benchmarks.csproj \
  --configuration Release \
  -- --filter '*'
```

## Results

Lower execution time is better. The reduction is calculated from the displayed mean values.

| Method | Baseline | Optimized | Time reduction |
|---|---:|---:|---:|
| ToCartesian | 13.148 ns | 12.838 ns | 2.36% |
| ToGeocentric | 28.499 ns | 26.149 ns | 8.25% |
| Recalc | 738.160 ns | 627.536 ns | 14.99% |
| ShuMgnp | 355.187 ns | 335.031 ns | 5.67% |
| IgrfGeo | 343.970 ns | 335.683 ns | 2.41% |
| IgrfGsw | 338.475 ns | 333.498 ns | 1.47% |
| Dip | 15.258 ns | 4.596 ns | 69.88% |
| Trace_NS | 251,906.962 ns | 247,598.097 ns | 1.71% |
| Trace_SN | 244,311.802 ns | 243,255.598 ns | 0.43% |

`Recalc` allocations remain unchanged at 2,896 bytes per call. `Trace_NS` and `Trace_SN` allocations also remain unchanged at 16,218 and 16,217 bytes respectively. The optimizations reduce computation rather than changing ownership or mutability of the returned data.

## Retained Changes

- `Dip`: fixed-exponent `Math.Pow(x, 2.5)` replaced with multiplication and `Math.Sqrt`.
- `Recalc`: invariant `REC` and normalization factors precomputed once; each context still owns its mutable arrays.
- `ShuMgnp`: redundant square roots and the final repeated `SinCos` removed from the Newton iteration.
- `IgrfGeo` and `IgrfGsw`: triangular coefficient indices updated incrementally in the inner loops.
- Spherical and geodetic coordinate conversion: paired `Sin` and `Cos` calls replaced with `Math.SinCos`.

The double-angle substitution in `Sun` and the cosine-difference identity in `ToGeodetic` were also tested, but were reverted because they did not demonstrate an improvement on this platform.

Small differences, especially `Trace_SN`, should be interpreted with the short-run measurement variance in mind. The largest improvements are independently visible in both execution time and the underlying reduction in computational work.
